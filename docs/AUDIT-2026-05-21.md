# Debrief Audit — 2026-05-21

Audit run at v1.9.8 on `main`. Health + security + functional QA via static review and dependency audits. App was not run interactively (Electron desktop, no automated harness).

**Original verdict (at audit time):** Not ready for broader release. Recent fix sprint was sound, but audit found 3 critical security holes, 3 critical functional bugs (incl. silent data loss), and a broken dev environment.

No remaining data-loss or RCE-equivalent paths. Still open: Tier 1 HIGH items below, including the `npm audit` advisories (currently 11: 6 high / 3 moderate / 2 low — see H-11) and Tier 2.

## Tier 1 — next sprint

Roughly in priority order. Branch suggestion: `tier1-high-fixes`.

- [x] **H-3: Sidecar shared-secret auth.** _(Phase B.)_ `SidecarManager` generates a per-launch `crypto.randomBytes(32)` token, passes it via `DEBRIEF_SIDECAR_TOKEN` env to `server.py`, which enforces `Authorization: Bearer <token>` (constant-time compare) in an HTTP middleware on every route; the manager's `/healthz` poll and all `sidecar-client.js` calls (`/analyse`, `/rediarise`, `/embed`) send the header. Fails open with a warning only if the env var is unset (manual dev runs). **Needs an app launch to confirm the sidecar still starts + serves.**
- [x] **H-4: Replace `exec` with `execFile`/`spawn` for ffmpeg.** _(Phase B.)_ All four shell-string ffmpeg calls in `electron.js` (transcode, duration probe ×2, extract-audio) now use `execFile` with an argv array — no shell, so paths can't inject. Sidecar already used `spawn`. **Needs an app launch to confirm ffmpeg extraction/probe still work.**
- [x] **H-5: Lock down `safe-file://` protocol.** _(Phase B.)_ The handler now allow-lists requested paths against `transcripts.file_path` (both sides `path.resolve`-normalised) before streaming, so XSS can no longer `fetch('safe-file:///…/.ssh/id_rsa')`. **Needs an app launch to confirm media playback still works.**
- [x] **H-2: Sanitize LanceDB filter strings.** _(Phase B; superseded by H-18.)_ Originally added `sqlStringLiteral()` escaping at the 4 `.where()`/`.delete()` interpolations. H-18 then removed all string `.where()`/predicate usage entirely (the LanceDB 0.20 bug made them no-ops anyway), so the injection surface is gone and the escaping helper was deleted — filtering/deleting now happens in JS / via rebuild, with no renderer-controlled string reaching a Lance SQL predicate.
- [ ] **H-6: Enable Electron sandbox.** Set `sandbox: true` in `createWindow` webPreferences (`public/electron.js:716`). Drop `--no-sandbox` from `package.json:13, 16`. Verify nothing in the preload assumes Node access.
- [x] **H-7: Verify python-build-standalone SHA-256.** _(Phase C.)_ `bundle-python.sh` now downloads the release's aggregate `SHA256SUMS`, extracts the exact asset's digest (awk `$2 ==`, so the `_stripped` variant isn't confused), and fails closed on mismatch/missing before extracting. (PBS publishes one `SHA256SUMS`, not per-asset `.sha256` sidecars — verified.)
- [x] **H-8: Pin HuggingFace model revisions.** _(Phase C.)_ All 6 repos in `prefetch-models.py` now carry a `revision=<commit-sha>` passed to `snapshot_download`; the loop hard-errors if any entry lacks one. SHAs resolved via the HF metadata API (works for gated repos too).
- [x] **H-9: Pin GHA actions to commit SHAs.** _(Phase C.)_ All `uses: actions/*` in `release.yml` + `ci.yml` pinned to commit SHAs with `# vN` comments; added `.github/dependabot.yml` (github-actions + npm, grouped minor/patch) so the pins stay current.
- [ ] **H-10: Bump Electron to a release that fixes GHSA-5rqw-r77c-jp79 + GHSA-xj5x-m3f3-5x3h** (≥ v42). Re-test IPC after — major version.
- [ ] **H-11: Upgrade `electron-rebuild` past the `tar`/`cacache` advisories.** From `npm audit`.
- [x] **H-12: Windows filename parsing.** _(Phase A.)_ The renderer has no Node `path` module, so added a cross-platform `getBasename` helper (splits on `/` and `\`) in `src/utils/helpers.ts` and used it at all 5 sites (UploadPage ×3, ProcessingQueue, TranscriptDetailPage).
- [x] **H-13: Cleanup extracted WAVs on error/cancel.** _(Phase A.)_ Hoisted `audioPath` above the try and moved `deleteFile` into a `finally` in `fileProcessor.ts`, so cancelled/failed video imports no longer leak temp WAVs.
- [x] **H-14: Auto-update — wired up.** _(Phase D; chose to make it real.)_ Installed `electron-updater@6.8.3` (runtime dep) and added `setupAutoUpdater()` in `electron.js`: packaged-only `checkForUpdatesAndNotify()` with event logging. Feed comes from the existing `electron-builder.json` `publish` (github/michael-borck/debrief) via app-update.yml. **Needs a real tagged release to verify end-to-end; macOS auto-update requires the signed+notarized zip target (present). Windows builds are unsigned, so Win auto-update will warn — revisit when Win signing lands.**
- [x] **H-15: `change-database-location` half-truth.** _(Phase D; chose clarify.)_ Settings now states "Change Location moves the database file only" (models/venv/vector store stay in app data), and the success alert says "Database file moved."
- [ ] **H-16: `isMounted` / cancellation in async `useEffect`s.** Roughly 12 detail-page loaders (`TranscriptDetailPage.tsx:53, 104`, `ProjectContext.tsx:46`, `ProjectChatModal`, `TopicsTab`, etc.). Pattern is in `ServiceContext.tsx:148` and `FirstLaunchSetup.tsx:22`.
- [x] **H-17: Trash "30-day auto-delete" — now real.** _(Phase D; chose implement.)_ Added `db-rpc/maintenance.js` `sweepExpiredTrash()` (purges transcripts/projects with `deleted_at` older than 30 days; FK cascade clears children), called once per launch in `electron.js` after `initDatabase`. - [x] **H-18: LanceDB `.where()` bug IS broader — verified + fixed.** _(Phase E.)_ Confirmed against real LanceDB 0.20: string-equality predicates on Utf8 columns return 0 rows (numeric work, strings don't — regardless of quoting).
